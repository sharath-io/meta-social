A social media app

meta-social is a platform for sharing projects and interests, allowing users to create and filter posts,
follow others, and view user profiles. Features include create, edit and delete posts, like & bookmark, and
tracking followers and following counts. Built with React JS, it leverages useContext and useReducer for
state management and vanilla CSS for styling.
